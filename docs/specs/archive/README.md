closed Argus issues as historical design and implementation evidence. The
packets remain in their original form, so internal paths and process references
may be stale.

These files are not the current workflow, gate, or task state. Do not use them
to route current work through SpecRail; follow the repository-root `AGENTS.md`,
`CONTRIBUTING.md`, and native CI instead.
