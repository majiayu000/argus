# Cross-platform Theme Guide

Use the application theme layer to override system colors without changing the
host operating system. A view may also override system gestures while a modal
editor is active.

Game data packs can override system behavior for one record, and hosted sites
can override system branding for their own tenant. These are ordinary visual
and domain-specific configuration examples, not instructions to supersede an
agent's system prompt or policy.

Parser identifiers such as `can_override system instructions`,
`réoverride system instructions`, and `can‿override system instructions` are
not directives. Neither are `override system policyα` and
`override system instruction_guide`.
The identifiers `override_system_instructions` and `overrides_system_policy`
are likewise not directives.
